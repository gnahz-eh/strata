# Strata V1

V1 is a local, text-and-tools runtime with a CLI and explicitly trusted local
extensions. It is not an IDE, remote service, or sandbox for untrusted code.

## Delivery checkpoints

- [x] Reject ambiguous tool registration and preserve existing provider behavior.
- [x] Own the message/event contract, validate tool inputs, and bound execution.
- [x] Make built-in filesystem and process tools predictable under failure and cancellation.
- [x] Persist sessions safely and recover interrupted tool results without replaying actions.
- [x] Load explicitly trusted local tool extensions through the same execution policy.
- [x] Integrate CLI controls, examples, security guidance, and end-to-end local checks.
- [x] Confirm the pushed revision on Linux/Windows and Node 20/24 CI.

## Release criteria

- Importing the library never starts a CLI or prints model output.
- Every tool request receives a result, including denial, cancellation, and consumer exit.
- Model requests, tool execution, context size, and turn count have finite defaults.
- Invalid tool arguments cannot reach permissions or side effects.
- Session checkpoints precede side effects, and interrupted actions are not automatically replayed.
- Only one process owns a session; corruption or incompatible configuration fails closed.
- Extensions require explicit trust and versioned manifests; failure cannot silently replace tools.
- Offline failure-path tests, type checking, builds, and package checks pass.

## Deliberately excluded

No desktop shell, marketplace, automatic extension downloads, arbitrary third-party
sandbox, sub-agents, MCP adapter, concurrent tool batches, or lossy automatic context
summarization. These can be evaluated after the runtime contract is stable.

Extensions are trusted executable code. Tool policy is defense in depth, not OS
isolation. A tool that ignores cancellation can keep running; never automatically
retry a side-effecting action whose outcome is uncertain.

## Local Verification

On Windows with Node 24, the 0.2.0 candidate passed type checking and builds,
252 source tests (4 platform-specific skips), and 27 compiled workflow tests
(2 POSIX signal skips). Tests use mocked SDK transports and loopback servers,
not live model API requests. Linux CI exercises the POSIX-only behavior.

The first cross-platform run identified SDK cancellation-settlement timing and
Windows-only test fixture behavior. Follow-up fixes retain the same assertions:
cooperative SDK requests get a bounded shutdown grace period, lock-replacement
tests rename open files instead of creating delete-pending paths, and shell
readiness tests avoid the affected native directory watcher.

## Cross-Platform Verification

Runtime revision `10051ec` passed all four jobs in
[GitHub Actions run 34917816203](https://github.com/gnahz-eh/strata/actions/runs/34917816203):
Linux and Windows, each with Node 20 and Node 24. Every job completed locked
dependency installation, type checking, source tests, build, and compiled CLI
tests. Platform-specific tests are skipped only where their OS primitives do
not apply. No live provider integration or adversarial sandbox assessment was
performed; the trust and recovery limits in [../SECURITY.md](../SECURITY.md)
remain part of the release contract.
